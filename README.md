# Move Up Academy · Word Lab

听音选四图词汇练习。包含 Let’s Begin 1、Let’s Begin 2、Let’s Go 1、Let’s Go 2。

## 运行

将 index.html 和 logo.jpg 放在同一个目录，使用浏览器打开 index.html，或上传至静态网站服务器。无需安装依赖。

每轮16题练习，完成后解锁8题挑战，8题全对通关。进度保存于当前浏览器 localStorage，发音使用浏览器 SpeechSynthesis，实际支持情况取决于设备和浏览器。
